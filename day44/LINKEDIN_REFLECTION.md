# LinkedIn Reflection

Built a **Customer Intelligence Dashboard with Streamlit** as part of Day 44 of my analytics project journey.

The goal was to turn raw customer-level data into a business-friendly decision-support interface. I implemented KPI cards, customer segmentation, churn-rate analysis, churn-risk distribution, interactive filters, CSV upload support, and a high-risk customer watchlist.

The key learning was that an analytics dashboard is not just a collection of charts. The useful part is connecting metrics to business questions: *How many customers do we have? How much revenue is at stake? Which segments show higher churn? Which customers need attention first?*

This project also strengthened my understanding of data preparation, interactive visualization, Streamlit application design, and translating analytical outputs into an executive-friendly workflow.

Next step: connect the dashboard to a live data source and replace the synthetic churn-risk logic with a validated production ML model.
