# Customer Intelligence Platform — Day 52

## Capstone Phase: Frontend Integration

A React + Vite dashboard demonstrating the customer analytics workflow.

## Features

- Overview dashboard
- KPI cards
- Customer search
- City and segment filters
- Customer table
- Churn prediction view
- Analytics view
- Customer detail drawer
- Explainability summary
- Responsive UI
- UX documentation

## Run

```powershell
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Build

```powershell
npm run build
```

The production build is generated in `dist/`.

## Project Structure

```text
src/
  main.jsx
  data.js
  styles.css
reports/
  ux_design_report.md
  linkedin_reflection.md
screenshots/
```

## Note

This Day 52 frontend uses demonstration data in `src/data.js`. Replace it with API responses from the real Customer Intelligence Platform backend for production integration.
