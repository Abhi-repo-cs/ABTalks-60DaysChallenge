# Day 49 LinkedIn Reflection

🚀 Day 49/60 — Building My First Working Capstone Baseline

Today I moved my Customer Intelligence Platform from individual components toward an integrated working prototype.

The focus was on connecting:

📥 Raw customer data  
→ 🧹 Preprocessing  
→ ⚙️ Feature engineering  
→ 🤖 Baseline ML model  
→ 📊 Evaluation  
→ 🔮 Prediction outputs

For the first predictive baseline, I used **Logistic Regression** for customer churn prediction.

The goal wasn't to build the most sophisticated model immediately. Instead, I wanted to establish a reliable benchmark and validate the complete end-to-end workflow.

### What I implemented
• Integrated preprocessing and ML workflows  
• Built a reusable prediction pipeline  
• Generated churn probabilities  
• Evaluated the baseline using accuracy, precision, recall, F1 and ROC-AUC  
• Saved prediction outputs and the trained pipeline  
• Documented strengths, limitations and next steps

One important engineering lesson from today:

**A working baseline is more valuable than an isolated sophisticated component.**

Now the capstone has a measurable starting point that future models and improvements can be compared against.
