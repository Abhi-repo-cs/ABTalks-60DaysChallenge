# Fraud Detection Using Random Forest

## Objective

Detect fraudulent financial transactions using ensemble learning.

## Dataset

The dataset contains transaction-related features such as:
- Transaction Amount
- Transaction Hour
- Account Age
- Failed Transactions
- Device Trust Score
- Location Change
- International Transaction
- Transaction Frequency

## Models

1. Decision Tree
2. Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Feature Importance

Random Forest feature importance was analyzed to identify
the strongest indicators of fraudulent transactions.

## Robustness

The Random Forest model was evaluated using multiple
train-test splits to assess performance stability.

## Challenges

- Class imbalance
- False positives
- False negatives
- Changing fraud patterns
- Data quality
- Real-time detection

## Technologies

Python
Pandas
NumPy
Scikit-learn
Matplotlib

## Conclusion

Random Forest provides a robust ensemble-based approach
for detecting fraudulent transactions and generally
reduces overfitting compared with a single Decision Tree.
