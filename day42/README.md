# Day 42 — Sprint Review & Business Intelligence Integration

## Objective
Integrate forecasting, KPI tracking, retention analytics, and predictive customer risk scoring into a unified Business Intelligence (BI) workflow.

## Deliverables
- Integrated BI notebook/app
- Architecture workflow diagram
- Business intelligence report
- Week 6 reflection
- GitHub-ready repository structure

## Unified Workflow
1. Ingest customer/business data
2. Clean and validate data
3. Calculate executive KPIs
4. Generate forecast signals
5. Calculate retention/churn indicators
6. Score customer risk
7. Segment and rank customers
8. Surface insights in an executive dashboard
9. Recommend business actions
10. Track outcomes and iterate

## Suggested Tech Stack
Python, Pandas, NumPy, Matplotlib, Scikit-learn, Plotly/Streamlit, Jupyter Notebook.

## Run
Install dependencies:
`pip install -r requirements.txt`

Run the Streamlit app:
`streamlit run app/app.py`

Open the notebook:
`notebook/day42_integrated_bi.ipynb`
