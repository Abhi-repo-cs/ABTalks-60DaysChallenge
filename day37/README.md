# Day 37 - Business Forecasting

## Run

```bash
pip install pandas matplotlib statsmodels
python day37.py
```

The script forecasts 12 months of revenue using ARIMA(1,1,1), evaluates a 6-month holdout, creates a visualization, and writes a business report.

## Files

- `day37.py` — main forecasting script
- `revenue_data.csv` — sample monthly revenue data
- `forecast_visualization.png` — generated forecast chart
- `business_forecasting_report.md` — business implications and accuracy report
