# Data Dictionary

| Field | Description |
|---|---|
| customer_id | Unique synthetic customer identifier |
| tenure_months | Customer tenure in months |
| monthly_spend | Approximate monthly customer spend |
| logins_30d | Number of logins in the previous 30 days |
| support_tickets_30d | Support tickets in the previous 30 days |
| days_since_login | Days since the customer's last login |
| payment_failures_90d | Payment failures during the previous 90 days |
| feature_usage_pct | Product feature usage percentage |
| satisfaction_score | Customer satisfaction score from 1 to 10 |
| segment | Behavioral/value customer segment |
| churned | Synthetic historical churn target |
| churn_probability | Model-estimated probability of churn |
| risk_band | High, Medium, or Low risk |
| risk_rank | Rank based on predicted churn probability |
| recommended_retention_strategy | Suggested action based on risk and signals |
