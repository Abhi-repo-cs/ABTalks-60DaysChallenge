# Day 39 — Business KPI Analytics

## Project
An executive KPI monitoring dashboard for customer, revenue, retention, and unit-economics analytics.

## Files
- `day39.py` — Streamlit interactive KPI dashboard
- `day39_kpi_notebook.ipynb` — KPI analytics notebook
- `business_kpi_data.csv` — synthetic monthly KPI dataset
- `business_kpi_report.md` — executive-level business KPI report
- `screenshots/` — visualization screenshots
- `requirements.txt` — Python dependencies

## Run the dashboard
```bash
pip install -r requirements.txt
streamlit run day39.py
```

## KPI Coverage
Customer growth, revenue growth, retention, churn, ARPU, AOV, active customers, and net customer additions.

## Learning Outcome
The project demonstrates how raw business metrics can be converted into an executive monitoring layer that supports strategic decisions.
