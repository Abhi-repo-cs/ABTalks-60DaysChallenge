# Day 29 - Customer Segmentation

## Objective

Customer segmentation using K-Means clustering.

## Technologies

Python
Pandas
NumPy
Scikit-learn
Matplotlib

## Machine Learning Technique

K-Means Clustering

## Features

Age
Annual Income
Spending Score

## Evaluation

Elbow Method
Silhouette Score

## Results

The model identified distinct customer segments
with different income, age, and spending patterns.

## Business Impact

The identified segments can be used for:

- Personalized marketing
- Customer targeting
- Loyalty programs
- Product recommendations
- Customer retention
